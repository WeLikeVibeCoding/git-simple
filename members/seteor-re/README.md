# 我的 Git 学习笔记

## 第一次 Git 实验总结

1. `git add` 的作用是：
   将工作区中指定文件的修改添加到暂存区，为之后的提交做好准备。

2. `git commit` 的作用是：
   将暂存区中的修改保存到本地 Git 仓库中，形成一个新的版本记录。

3. 本次实验中 `git restore notes.md` 的作用是：
   撤销工作区中对 `notes.md` 文件尚未提交的修改，使文件恢复到修改之前的状态。

4. `commit` 与 `push` 的区别是：
   `commit` 是把修改提交到本地 Git 仓库；`push` 是把本地已经提交的内容上传到 GitHub 远程仓库。
