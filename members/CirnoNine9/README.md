# 我的 Git 学习笔记

## 第一次 Git 实验总结

1. `git add` 的作用是：把指定文件当前的修改放入暂存区，供下一次提交使用。它只负责暂存，不会创建提交。
2. `git commit` 的作用是：把暂存区中的内容保存为一次本地提交，并附上说明，形成可追溯的版本记录。
3. 本次实验中 `git restore notes.md` 的作用是：用暂存区中的版本覆盖工作区的 `notes.md`，丢弃该文件尚未暂存的修改；它不会撤销已经暂存的修改。
4. `commit` 与 `push` 的区别是：`commit` 把改动记录在本地仓库，`push` 则把本地提交发送到远端仓库，供他人查看和协作。
