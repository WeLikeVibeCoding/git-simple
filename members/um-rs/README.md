# 我的 Git 学习笔记

`git add` 的作用是：把工作区里改过的文件放进暂存区，标记成「下次提交要带上的内容」。这时还没有写进版本历史。

`git commit` 的作用是：把暂存区里的内容做成一次提交，记进本地仓库，并配上说明。这次记录只在自己电脑上。

本次实验中 `git restore notes.md` 的作用是：`notes.md` 末尾多了一句还没 `git add` 的练习文字。这条命令把工作区里的 `notes.md` 恢复成上次提交时的样子，那句话消失，已有提交不变。

`commit` 与 `push` 的区别是：`commit` 把版本存在本地仓库；`push` 把本地提交送到 GitHub。不 push，网页上的仓库看不到这次提交。
